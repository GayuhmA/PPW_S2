Perbedaan Attribute DISABLED dan READONLY

Tabel Perbandingan

Aspek DISABLED READONLY
Fungsi Utama Menonaktifkan elemen form sepenuhnya Membuat elemen form tidak bisa diedit
Tampilan Elemen terlihat abu-abu/pucat Elemen terlihat normal
Interaksi User User tidak bisa berinteraksi sama sekali User bisa memilih dan menyalin isi
Submit Form Data TIDAK dikirim ke server Data tetap DIKIRIM ke server
Focus Tidak bisa mendapat focus Bisa mendapat focus
Tipe Input Semua jenis input Text, password, textarea, email, url, search, tel

Contoh 1: Attribute DISABLED










Catatan: Dengan disabled, elemen terlihat pucat dan user tidak bisa mengubah nilai. Data juga tidak akan dikirim saat form disubmit.

Contoh 2: Attribute READONLY










Catatan: Dengan readonly, elemen terlihat normal dan user bisa memilih/menyalin teks. Data tetap akan dikirim ke server saat form disubmit.

Kesimpulan

DISABLED: Gunakan ketika Anda ingin sepenuhnya menonaktifkan suatu elemen form. Data tidak akan dikirim ke server, dan user tidak bisa berinteraksi dengan elemen tersebut.

READONLY: Gunakan ketika Anda ingin menampilkan informasi yang tidak bisa diedit tetapi tetap perlu dikirim ke server. User bisa memilih dan menyalin teks, tapi tidak bisa mengubahnya.
